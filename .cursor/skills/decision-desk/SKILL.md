# Decision Desk

Используй для данных к решению, buy/sell с целями, контуров ботов и live-метрик Hyperliquid.

## Перед ответом

```bash
python3 .cursor/skills/decision-desk/fetch_decision_context.py --symbol BTC -o /tmp/decision_ctx.json
```

UI: `npm run dev` в корне репозитория. Снимки: `data/decision-desk/`.

Не финансовый совет.
